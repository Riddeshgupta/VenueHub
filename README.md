# VenueHub

VenueHub is a multi-vendor event venue marketplace where customers can discover venues, compare venues and quotations, check availability, request quotations, and book venues.

## User Roles
1. **Customer**: Discover venues, compare options, request quotations, check availability, and manage bookings.
2. **Venue Owner**: List venues, manage pricing and availability, respond to quotation requests, and manage bookings.
3. **Admin**: Oversee platform users, venue listings, quotations, platform settings, and reports.

## Technology Stack
- **Frontend**: React + JavaScript
- **Backend**: Python + Flask
- **Database**: MySQL
- **API Communication**: REST API
- **Authentication**: JWT (JSON Web Tokens)
- **Version Control**: Git
